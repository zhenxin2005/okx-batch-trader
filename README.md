# OKX 批量交易工具

基于 Python + Streamlit 的 OKX 交易所批量交易 Web 应用，支持行情筛选、多选、一键批量买入/卖出。

## ✨ 功能特性

- ⚙️ **网页端 API 配置** - 密钥直接在网页侧边栏填写/修改，实时显示连接状态和错误原因，无需手动编辑配置文件
- 📊 **实时行情** - 自动刷新所有 USDT 现货交易对（可设置 3/5/10/30 秒间隔）
- 🔍 **多条件筛选** - 按价格区间、24h 涨跌幅区间、交易量、关键词、是否持仓筛选
- 💼 **持仓显示** - 表格直接显示每个币的持仓数量和持仓价值（USDT）
- ☑️ **勾选交易** - 表格中勾选币种，自动刷新后勾选状态不丢失
- 🚀 **批量买入** - 一键买入所有选中币种（每币等额 USDT）
- 💸 **批量卖出** - 支持两种模式：全部卖出持仓 / 按金额卖出
- 🛡️ **安全优先** - 默认模拟交易模式，下单前需勾选确认 + 余额预检 + 密钥无效时禁止交易
- 📱 **响应式 UI** - 深色主题，专业交易界面

## 🚀 快速开始

### 1. 打开 OKX 桌面客户端（重要！）

本工具默认通过 OKX 桌面客户端的本地 SOCKS5 代理联网（`127.0.0.1:17001`），
**使用前必须先启动 OKX 客户端并保持运行**，否则会提示"获取行情失败"。

### 2. 安装依赖

```bash
cd okx-batch-trader
pip install -r requirements.txt
```

### 3. 配置 API 密钥

**方式一（推荐）：网页配置**
启动应用后，在左侧「⚙️ API 配置 → 密钥设置」中填入 API Key / Secret Key / Passphrase，
点「💾 保存配置」即可。配置会自动保存到本地 `.env` 文件，重启无需重填；
连接状态和错误原因会直接显示在页面上。

**方式二：手动编辑文件**

```bash
cp .env.example .env
```

编辑 `.env` 文件，填入你的 OKX API 密钥：

```env
OKX_API_KEY=你的API Key
OKX_SECRET_KEY=你的Secret Key
OKX_PASSPHRASE=你的Passphrase
OKX_USE_DEMO=True
```

> ⚠️ 模拟盘和实盘的 API 密钥是**分开的**：模拟盘密钥要在 OKX → 头像 → API → 「模拟交易」
> 标签页下创建，用实盘密钥连模拟盘会报 `50105 Passphrase incorrect`。

### 4. 获取 OKX API 密钥

1. 登录 [OKX 官网](https://www.okx.com)
2. 进入 **用户中心 → API**
3. 创建 API Key，设置 **读取 + 交易** 权限（不要开通提现权限）
4. 设置 Passphrase（自定义密码，自己记住）
5. 如果提示 IP 白名单，先跳过或填 `0.0.0.0/0`

### 5. 启动应用

```bash
streamlit run app.py
```

应用将在浏览器中自动打开，默认地址: http://localhost:8501

### 6. 领取模拟资金（测试前必做）

模拟盘默认没有资金。登录 OKX 网页/App → **交易 → 模拟交易**，领取模拟 USDT，
否则页面余额显示为 0、无法下单。

## 📖 使用指南

### 筛选币种

在左侧边栏设置筛选条件（留空表示不限制）：

- **最低价/最高价** - 筛选价格区间
- **最小/最大涨跌%** - 筛选 24h 涨跌幅范围
- **最小交易量** - 筛选 24h 交易量（USDT）
- **搜索交易对** - 按名称搜索，如输入 `BTC`
- **只看已持仓** - 只显示当前持有余额的币种

### 选择币种

1. 在行情表格第一列勾选要交易的币种
2. 自动刷新后勾选状态保持不变
3. 点击表头可排序，快速找到目标币种

### 批量买入

1. 在「批量买入」区设置「每币买入金额」（如 100 USDT）
2. 确认已选数量和预计总花费
3. 勾选「我确认要执行以上买入操作」
4. 点击「一键买入」按钮
5. 查看逐币下单结果（成功/失败原因/订单号）

### 批量卖出

1. 勾选要卖出的币种
2. 选择卖出方式：
   - **全部卖出** - 卖出该币的全部可用持仓
   - **按金额卖出** - 每币卖出指定金额（USDT），由 OKX 自动折算成币的数量
3. 勾选确认后点击「一键卖出」

## ⚠️ 网络问题（重要）

**默认方案**：程序走 OKX 桌面客户端自带的本地 SOCKS5 代理（`127.0.0.1:17001`），
只要客户端开着就能连，无需 VPN。

如果这样仍然连不上（或你没有 OKX 客户端），再尝试下面的方案。

### 问题表现

启动后点击「刷新行情」没反应，或报错 `getaddrinfo failed` / `ConnectError`。

### 解决方案

#### 方案 A：使用 VPN/代理（推荐）

开启全局模式 VPN，然后刷新页面重试。

#### 方案 B：配置本地代理

如果你有本地代理软件（如 Clash、V2Ray），在 `.env` 里添加：

```env
HTTP_PROXY=http://127.0.0.1:7890
HTTPS_PROXY=http://127.0.0.1:7890
```

把 `7890` 改成你代理软件的本地端口（Clash 默认 7890，V2Ray 默认 10809）。

#### 方案 C：修改 OKX 域名

编辑 `.env`，添加国内可访问的域名：

```env
OKX_DOMAIN=https://www.okx.cab
```

也可以在 `.env` 里修改代理地址（默认走 OKX 客户端的 SOCKS5 代理）：

```env
OKX_PROXY=socks5://127.0.0.1:17001
```

## 🔧 技术栈

- **Python 3.11** - 编程语言
- **Streamlit** - Web UI 框架（`st.data_editor` 勾选表格 + `st.fragment` 局部自动刷新）
- **httpx** - HTTP 请求（直连 OKX REST API，签名用 HMAC-SHA256）
- **pandas** - 数据处理
- **python-dotenv** - 环境变量管理

## 🐛 常见问题

**Q: 提示 "未配置 API 密钥"？**
A: 请检查 `.env` 文件是否存在且配置正确。

**Q: 无法获取行情数据 / 报错 getaddrinfo failed？**
A: 网络问题，参考上方「网络问题」章节配置代理或 VPN。

**Q: 模拟交易和实盘有什么区别？**
A: 模拟交易使用 OKX 的模拟资金，不会产生真实盈亏。将 `OKX_USE_DEMO=False` 切换到实盘。

**Q: 批量下单有数量限制吗？**
A: 程序逐单顺序提交（每单间隔 0.1 秒），没有数量限制；某单失败不影响已成交的订单。

**Q: 为什么 Passphrase 不对？**
A: Passphrase 是创建 API 时你自己设置的密码，不是备注名。去 OKX API 管理页面确认。
